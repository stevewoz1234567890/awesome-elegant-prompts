## Prompts

1. **Full presentation builder**

```text
Act as a world-class presentation creator. Create a complete, slide-by-slide presentation on the topic: [topic]. Include title slides, key points, examples, data, metaphors, visuals suggestions, and a closing call-to-action. Structure it like a TED-level presentation with storytelling flow.
```

2. **Deep research presentation**

```text
Create a full presentation on [topic] using deep research. Include real statistics, case studies, expert quotes, practical insights, and examples. Make each slide educational, engaging, and backed by credible sources. Provide references at the end.
```

3. **Simplified explanation presentation**

```text
Build a presentation on [topic] designed for beginners. Break down complex concepts into simple explanations, analogies, and step-by-step logic. Make the content so clear that even a 10-year-old can understand the full topic.
```

4. **Business pitch presentation**

```text
Create a complete investor-style pitch deck for my business idea: [business idea]. Include problem, solution, market size, product features, business model, competitive advantage, financial projections, team slide, and closing pitch script.
```

5. **Storytelling master presentation**

```text
Create a complete presentation on [topic] using storytelling structure: Hook → Conflict → Journey → Insight → Transformation → Call to Action. Make slides emotional, memorable, and persuasive. Add speaker notes with delivery guidance.
```

6. **Corporate presentation**

```text
Create a formal, corporate-style presentation on [topic]. Include professional tone, structured bullet points, charts, graphs, SWOT analysis, trends, forecasts, and data-backed recommendations. Make it suitable for boardrooms.
```

7. **Presentation + script combo**

```text
Create a fully ready presentation on [topic], AND write a complete spoken script I can read while presenting. Ensure the script matches the tone, pacing, and emotional flow of the slides. Include pauses, emphasis, storytelling cues, and delivery instructions.
```
