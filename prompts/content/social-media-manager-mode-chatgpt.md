## Prompts

ChatGPT has a secret feature called Social Media Manager Mode.

You can use it to manage your entire social media like a $5000/month social media manager for free. Here are 8 prompts to access it:

1. **The full social media manager prompt**

```text
Act as my full-time social media manager for the niche [insert niche]. Create a 30-day content strategy covering reels, single posts, hooks, CTAs, posting times, and engagement rules. Make it so detailed that I only need to copy-paste and post.
```

2. **Viral content factory**

```text
Generate 30 viral content ideas for [insert niche], each with a scroll-stopping hook, 3–step storyline, caption, CTA, and recommended visual. Ensure every idea is designed for maximum retention, engagement, and shareability.
```

3. **The caption and copywriting engine**

```text
Write 10 high-engagement captions for this topic: [insert topic]. Each caption must include a hook, relatable context, emotional pull, and strong call-to-action. It should be written in my brand voice: [insert tone].
```

4. **The 30-day posting calendar builder**

```text
Make a complete 30-day posting calendar for my page in the niche [insert niche]. Include post type, caption, hook, CTA, and suggested visuals for each day. Format it like a clean, easy-to-execute schedule.
```

5. **The competitor domination prompt**

```text
Analyze my top 5 competitors in the niche [insert niche]. Break down their best-performing content, tone, patterns, hooks, and topics. Then create a strategy that helps me outperform them in reach, engagement, and follower growth.
```

6. **Account growth accelerator**

```text
Based on my current page [paste link or stats], create a growth acceleration plan focused on: profile optimization, content themes, posting frequency, hashtag strategy, and engagement hacks. Make it beginner-proof and guaranteed to work.
```

7. **The social media branding architect**

```text
Design a complete brand identity for my social media presence in the niche [insert niche]. Include tone of voice, color direction, messaging, content archetype, posting style, and audience personality. Make it cohesive and recognizable.
```

8. **The reel script and shot guide prompt**

```text
Create 10 reel scripts for my niche [insert niche], each with camera instructions, dialogue, scene descriptions, transitions, and pacing tips. Make them optimized for high watch-time and viral potential.
```
