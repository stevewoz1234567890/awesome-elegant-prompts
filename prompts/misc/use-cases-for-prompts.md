## Use cases for prompts

### Q&A

Ask a question about an open topic or a specific text; get an answer.

### Chatbot

Have a conversation with the LLM from a specific role or point of view.

### Brainstorming

Create a list of ideas for a specific topic, idea, or problem.

### Creative writing

Create a new text (a poem, an email, a story) from a general idea you enter into the prompt.

### Extraction

Extract specific information from a reference text.

### Classification

Provide a reference text and a set of categories for the LLM to sort the text into.

### Summarization

Provide a reference text and get a summary of its contents, perhaps from a specific point of view.

### Rewriting

Have the LLM rewrite a reference text in a specific format, tone, or style.
