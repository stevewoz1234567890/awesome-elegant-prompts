## Prompts

1. **Complete Presentation Blueprint**

```text
Act as a professional presentation consultant. Create a complete presentation blueprint for [topic].

Define:
- objective
- target audience
- key message
- slide flow
- number of slides

Ensure the structure is logical, engaging, and professional.
```

2. **Slide Structure & Flow Architect**

```text
Design a slide-by-slide structure for a presentation on [topic].

For each slide:
- slide title
- the purpose of the slide

Make the deck flow naturally start to finish.
```

3. **Full Slide Content Generator**

```text
Create full content for each slide of a presentation on [topic].
Write concise, presentation-ready bullet points for every slide.

Audience: [describe audience]
Tone: [professional / friendly / technical]
```

4. **Story-Based Presentation Builder**

```text
Turn [topic] into a compelling presentation using a narrative structure:
hook → problem → insight → solution → takeaway

Make it engaging while remaining professional and informative.
```

5. **Visual Direction & Design**

```text
Suggest professional visual and design guidance for each slide of this presentation on [topic].

Recommend:
- layouts
- charts/diagrams
- icons/imagery
- visual hierarchy

Aim for a clean modern look.
```

6. **Slide Simplification & Clarity Editor**

```text
Rewrite the following slide content so it is slide-friendly.

Rules:
- reduce text
- sharpen key points
- one clear idea per slide

Content: [paste]
```

7. **Flow & Impact Polisher**

```text
Improve the flow, transitions, and impact of this presentation.

Rewrite:
- slide titles
- key bullets

So it feels smooth, confident, and professional end-to-end.
Content: [paste]
```
