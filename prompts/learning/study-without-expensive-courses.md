## Prompts

1. **Learning Blueprint Creator**

```text
I want to learn [subject/skill] from zero. Create a beginner-to-advanced roadmap with weekly milestones.
My goal level: [hobby / professional / exam]
Time available: [X hours/week]
```

2. **Smart Resource Curator**

```text
Recommend the best free online resources to learn [subject]. Include videos, articles, and practice tools that match my level.
My level: [beginner/intermediate]
Constraints: [no paid courses / mobile-friendly / etc]
```

3. **Personalized Tutor Simulator**

```text
Act like a private tutor for [subject]. Ask me 5 questions to test my understanding. Then give feedback with clear explanations and what to study next.
```

4. **Study Plan Optimizer**

```text
This is how much time I have each day to study [subject]: [time]. Design a time-efficient plan that keeps me consistent without burnout.
```

5. **Concept Simplifier**

```text
I’m stuck on this concept in [subject]: [paste concept].
Explain it like I’m 12 and include a simple example I can remember.
```

6. **Revision & Recall Booster**

```text
I want to retain what I’m learning in [subject]. Create a spaced-repetition system I can use weekly to reinforce key lessons.
Tools I use: [Anki/Notion/Google Sheets/etc]
```

7. **Progress Tracker Assistant**

```text
Help me create a simple system to track my learning progress in [subject], including goals, completed topics, and knowledge gaps.
Output as a table template I can copy into Notion or Sheets.
```
