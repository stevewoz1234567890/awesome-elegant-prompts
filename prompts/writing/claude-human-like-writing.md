## Prompts

1. **The Coffee Shop Test**

```text
Write this like you're explaining it to a friend over coffee. No marketing speak. No corporate jargon. Just straight talk about [topic]. If it sounds like a LinkedIn post, rewrite it.
```

2. **Voice Finder**

```text
Give me 5 different ways to say this same idea. Make each one sound like a different person wrote it: cynical, excited, skeptical, matter-of-fact, surprised.
Idea: [paste idea]
```

3. **AI Word Assassin**

```text
Rewrite this without any words that appear in typical AI-generated content. Ban these: "delve", "crucial", "leverage", "landscape", "robust", "game-changer". Use conversational alternatives.
Text: [paste text]
```

4. **Twitter Fight Mode**

```text
Write this like you're responding to someone who challenged you on Twitter/X. Keep it factual but add personality. Show some edge without being aggressive.
Topic: [topic]
```

5. **Story Time Formula**

```text
Take this topic and write it like you're telling a story about something that just happened to you. Start with "This is wild" or "Okay so". Make it feel spontaneous.
Topic: [topic]
```

6. **Rhythm Master**

```text
Write this in short, punchy sentences. Max 15 words per sentence. Vary the rhythm: some very short (3–5 words), some medium (8–12). Never three long sentences in a row.
Topic: [topic]
```

7. **Pattern Interrupt**

```text
Add one unexpected comparison or analogy that makes people stop scrolling. Don't use common comparisons. Make it weird but accurate.
Topic: [topic]
```

8. **Fluff Destroyer**

```text
Remove every adjective/adverb that doesn't add new information. If "very", "really", or "extremely" appears, cut it or replace with a stronger verb. Show, don't tell.
Text: [paste text]
```

9. **Contrarian Angle**

```text
Write this like you're contradicting conventional wisdom. Lead with what everyone gets wrong, then explain what's actually true. Make it feel like you're letting someone in on a secret.
Topic: [topic]
```

10. **Specificity Machine**

```text
Take this draft and add 3 specific examples or numbers. Replace every vague claim with concrete evidence. If you can't find real data, flag it so I can add it manually.
Draft: [paste draft]
```
